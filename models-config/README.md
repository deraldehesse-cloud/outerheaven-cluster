# Models & Agent Configurations - Outer Heaven Cluster

Zentrale Modellkonfigurationen, Ollama Modelfiles, Archetypen und System-Prompts für alle Cluster-Knoten.

## Enthaltene Module
- `Modelfile.megan`: Primäres Ollama-Modelfile für Megan auf Outer Heaven (DarkIdol / Llama 3)
- `character.json` & `character_canonical.json`: Persona-Spezifikationen, Lores und Bildgenerierungsregeln
- `config.yaml.example`: Vorlage für Hermes-Agenten- und Cluster-Konfigurationen
